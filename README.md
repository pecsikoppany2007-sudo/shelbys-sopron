# Shelby's Gin Bar, Sopron

Bemutató weboldal (kettő stúdió), az alapkészletre építve.

- Oldal: `site/` (Netlify publish könyvtár, build nincs)
- Beállítás: `oldal.json` → `python3 eszkozok/beallit.py`
- Ellenőrzés: `npm ci && npm test` (minőségkapu + Lighthouse mobil)
- Élesítés saját domainnel: `python3 eszkozok/elesites.py pelda.hu`
